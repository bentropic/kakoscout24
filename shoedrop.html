How to use it: (1) Right-click each reference photo above → Save Image, in order. (2) Open ChatGPT, attach all the saved photos to one message, same order. (3) Copy the full carousel prompt below and paste it into that same message. (4) Send — ChatGPT should generate every slide in one response. If it stops early, reply "continue with the rest".

Note on prices/text: image models sometimes render text imperfectly. If a price or label comes out blurry or wrong, ask ChatGPT to regenerate just that slide, or add the text afterward in CapCut/InShot/TikTok's text tool.
